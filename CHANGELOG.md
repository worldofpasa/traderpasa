# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-07-05

Initial public open-source release under the Apache-2.0 license.

### Added
- Self-hosted automated trading platform: strategy templates, evidence
  collection, AI synthesis, proposed orders, deterministic risk validation,
  broker execution, dashboards, and safety controls.
- Alpaca and Interactive Brokers adapters for paper and live US equities.
- AES-256-GCM encrypted credential vault for broker and model keys.
- Docker Compose deployment with Caddy reverse proxy.
- Bring-your-own-key AI via OpenAI, Anthropic, and OpenAI-compatible providers.
